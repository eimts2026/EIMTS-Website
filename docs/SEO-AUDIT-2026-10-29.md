# SEO implementation audit — 29 October 2026
Scope: source review of public homepage and shared SEO infrastructure. Production crawl and performance measurements remain pending.

## Implemented
- Expanded homepage and root description to 159 characters.
- Removed duplicate brand wording from homepage title; root template supplies the brand.
- Added Organization JSON-LD using the name, address, telephone and logo already published in the footer.
- Made vacancy and service headings describe recruitment intent.

## Screenshot findings
- Description: revised. Google has no mandatory 120–160 character limit; snippets vary by device/query.
- Schema: organization markup added. Existing job, FAQ and article schema was already present elsewhere.
- Keyword consistency: headings improved. Testimonial phrases in the audit are not sensible target keywords.
- Thin content: 679 words alone does not establish a quality problem. No filler added.
- Alt attributes: homepage hero and job cards have explicit empty alternatives. Hero imagery is marked decorative; job titles accompany card images. Missing versus empty attributes must be checked in the deployed DOM before declaring ten defects fixed.
- Performance: hero renders all slides plus a mobile image; potential loading contention needs a network/LCP baseline before changing carousel behavior. No measured speed improvement claimed.
- Links/GEO/usability: screenshot grades provide no individual findings. Full backlink, indexing and field Core Web Vitals assessment needs Search Console and live evidence.

## Existing infrastructure
Canonical paths, Open Graph/Twitter cards, robots and sitemap generators exist. Sitemap includes published jobs and articles. Homepage is dynamic. No deployment performed.

## Remaining verification
Production build, rendered desktop/mobile checks, JSON-LD validation, URL/status crawl and comparable Lighthouse measurements. Search Console indexing, impressions and clicks require account data.
References: https://developers.google.com/search/docs/appearance/snippet and https://developers.google.com/search/docs/fundamentals/seo-starter-guide

## Indexing pass
- Public homepage redirects from apex to www. Updated default site URL to www so canonicals and sitemap URLs use the destination host.
- Search Console property data unavailable; exclusions, sitemap processing and Google-selected canonicals remain unverified.
- Direct requests to live robots/sitemap failed DNS in this environment. Confirm after deployment.


## Job-page quality pass
- Job detail pages display title, summary, location/country, category, employment type, description, requirements when provided, application form, and closing date when provided. These fields are optional in the underlying data, so completeness varies by vacancy.
- Published expired jobs are now excluded from the detail lookup and sitemap, matching the listing query. The public cache can retain a newly expired job for up to 60 seconds.
- JobPosting description now includes summary, description and requirements. Optional dates are omitted when absent. The previous hiringOrganization used Emerald Isle, which is the recruitment agency rather than necessarily the employer; undisclosed employers now use Confidential.
- Data gap: store the actual hiring organization, application deadline and qualification detail per job when the employer permits disclosure. A posting without published_at lacks the Google-required datePosted and cannot be considered fully eligible for job rich results.
- Source-level validation: TypeScript and diff checks passed. Live Rich Results Test and sample rendered vacancy inspection remain outstanding because production access was unavailable.
